# RANDOM-ALL
This repository will contain in himself bat or py files, and with the help of it, you can randomize your operator/guns/builds etc. This project was made with pure enthusiasm. AI was used only as a tool, or as a function reminder, or something like that. The entire code was written by hand with the help of Python. 
After the launch of bat file you don't have to install anything. If you want to use the py file in the VSCode, you have to install Python v.3.15 (preferred). After that, you need to open .py file in the terminal.
The opening of bat file will follow you by just opening the CMD, nothing more.
